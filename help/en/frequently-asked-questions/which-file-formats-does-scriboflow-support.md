# Which file formats does Scriboflow support?

The supported format depends on whether the file becomes the contract or is added as an attachment.

## Contract source documents

**Import document** currently accepts PDF, DOC, DOCX, HTM, HTML, MD, TEXT and TXT files. A PDF remains a fixed document. Supported Word, text and HTML content can be converted for editing, although complex formatting may need review after conversion.

The filename extension must match the actual file type. Renaming an unsupported file does not convert it. Open the source locally and export a clean copy when an import fails.

## Contract attachments

Attachments currently support PDF, DOC, DOCX, TXT, MD, HTML, HTM, CSV, XLS, XLSX, PPT, PPTX, PNG, JPG, JPEG and WEBP. Current limits are 25 MB per attachment, up to 10 attachments and 100 MB in total for a contract.

Always preview or open the uploaded result before sending. A supported extension does not guarantee that a corrupted, password-protected or incomplete file can be processed.

For importing, see [Import an existing contract](/help/creating-and-managing-contracts/import-an-existing-contract). For supporting files, see [Add and manage contract attachments](/help/creating-and-managing-contracts/add-and-manage-contract-attachments).
