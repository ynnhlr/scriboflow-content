# Hvor Scriboflow opbevarer og behandler data

Scriboflow bruger flere infrastruktur- og tjenesteudbydere til at levere applikationen. Databehandlingen er ikke begrænset til ét land eller til EU.

## Primær databaseregion

Den primære produktionsdatabase er placeret i Frankfurt, Tyskland. Den opbevarer konto-, organisations-, kontrakt-, underskrifts- og relaterede applikationsdata.

## Yderligere behandling hos leverandører

Anden behandling kan finde sted i USA og på andre globale lokationer, som Scriboflows leverandører og deres underdatabehandlere bruger. Det omfatter tjenester til:

- Hosting og levering af applikationen
- Opbevaring af filer og genererede dokumenter
- Transaktionsmails
- Identitetsunderstøttet underskrift, når den vælges
- Fakturering og betalingsbehandling
- Driftsovervågning og analyse

Understøttede netværksforbindelser bruger TLS. Leverandørerne af database og objektlager dokumenterer kryptering ved lagring for de tjenester, Scriboflow bruger.

Leverandørernes roller, formål, datakategorier, behandlingssteder og overførselsgarantier er dokumenteret i det aktuelle [register over underdatabehandlere](/da/trust/subprocessors). Læs [Databehandleraftalen](/da/trust/dpa) for de kontraktvilkår, der gælder for kundestyrede personoplysninger.
