# Start a contract from a template

Starting from a template creates a new contract draft with reusable content already in place. The draft is independent, so contract-specific changes do not alter the template.

## Choose the template

1. Select **Use template** from the dashboard or the available contract-creation action.
2. Browse starter templates or your organisation's saved templates.
3. Open the relevant template and review its title or description.
4. Choose the action to create a contract from it.
5. Give the new contract a clear title.

If several saved versions look similar, stop and confirm which one your team currently uses. A clear template name helps avoid beginning with outdated wording.

## Complete the new draft

Review every section for the specific agreement. Add the parties and signees, fill required data fields and confirm that smart references show the correct values. Add or remove clauses where appropriate and attach any supporting documents.

Scriboflow saves editor-created drafts as you work. Before leaving, confirm that your latest changes appear. Editing this draft does not update the original template.

## Review before sending

Open **Preview** and check the complete document, party details, signer fields, attachments and signing settings. Correct any missing required values before moving to the sending step.

If the draft has become a useful new starting point, the **Make template** action may be available for editor-created contracts. Use it only when you intend to create a separate reusable template. See [Create a template from an existing contract](/help/templates-and-the-editor/create-a-template-from-an-existing-contract).
