# The contract preview or PDF is not loading

First protect any unsaved editor changes. A refresh can resolve a temporary display problem, but it should happen only after your recent work is safe.

## Check the contract state

If the contract is still being imported, converted or generated, keep the page open and allow processing to finish. Confirm that your internet connection is stable and that you remain signed into the correct organisation.

For an editor-created draft, copy any text not yet confirmed as saved. For an imported document, keep the original local file. Note whether the problem affects **Preview**, a download, or both.

## Retry the display

1. Close any duplicate tabs showing the same contract.
2. Reopen the contract from **Contracts**.
3. Try **Preview** again in a current supported browser.
4. If a download is available, save it locally and open it with a PDF reader.
5. Check whether attachments load separately from the main contract.

If a local PDF opens correctly while the browser preview does not, the issue may be limited to display. If neither works, do not send until the document has been checked.

## Contact support

Provide support with the organisation name, contract title or ID, contract status, whether it was editor-created or imported, browser, approximate time and exact error. Say whether the failure affects preview, download or both and whether other contracts load normally.

Do not create duplicate contracts as a workaround and do not send confidential files unless approved. For a completed agreement, see [Download the completed contract and signature certificate](/help/sending-and-signing/download-the-completed-contract-and-signature-certificate).
