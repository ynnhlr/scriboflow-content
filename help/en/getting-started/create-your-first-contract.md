# Create your first contract

You can begin with a blank contract, a template or an existing document. Whichever route you choose, Scriboflow keeps the contract as a draft until you send it.

## Choose a starting point

From the dashboard, choose the option that fits your document:

1. Select **Create new contract** to write the terms in Scriboflow's editor.
2. Select **Use template** to begin with reusable content from a starter or saved template.
3. Select **Import document** to upload a contract you already have.

For a detailed walkthrough of blank contracts, see [Create a contract from scratch](/help/creating-and-managing-contracts/create-a-contract-from-scratch). For file requirements, see [Import an existing contract](/help/creating-and-managing-contracts/import-an-existing-contract).

## Complete the contract

Give the contract a clear title, then add the relevant parties and signees. Write or review the terms, complete any required data fields and add attachments where needed. Scriboflow saves editor-created drafts as you work, but check that your latest changes appear before leaving the page.

Use **Preview** before sending. Confirm the document, party details, signees, signature choices and email information. Scriboflow shows any required information that still needs attention.

## Send when it is ready

When the review is complete, set the signing details and send the contract. Recipients receive a secure link to review and act on it. You can then follow its status from **Contracts** and open the activity history to see what happened.

If you want more detail before sending, continue with [Understand the contract flow](/help/getting-started/understand-the-contract-flow).
