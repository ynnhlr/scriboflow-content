# Edit and save a draft contract

You can leave an unfinished contract and return to it while it is still a draft.

## Open the draft

<!-- help-image:draft-contract -->
![Draft contract](../../assets/edit-and-save-a-draft-contract/draft-contract-v1.webp)

1. Open **Contracts**.
2. Filter by **Drafted** if needed.
3. Select the contract, or open its actions menu and choose **Edit**.

The contract opens at its current step. Use the step navigation to return to earlier sections such as **Parties**, **Terms** or **Attachments**.

## Make your changes

Update the contract name, parties, terms, attachments or signature setup as needed. Scriboflow saves supported draft changes automatically while you work. The status near the top of the contract shows when the latest changes were saved.

If Scriboflow temporarily saves a change locally, keep the page open until it has synchronized. If a save error appears, try again before continuing.

## Before leaving the draft

<!-- help-image:draft-saved -->
![Draft saved](../../assets/edit-and-save-a-draft-contract/draft-saved-v1.webp)

- Check that the saved status is current.
- Use **Preview** to review the latest document.
- Continue to the next step only when the current section is complete.

Once the contract has been sent, the current version is locked against normal editing. If a recipient requests changes, follow the change-request flow instead.
