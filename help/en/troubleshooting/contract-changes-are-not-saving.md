# Contract changes are not saving

Do not refresh or close the page immediately. First preserve any text that has not been saved, then check the connection and contract state.

## Protect your work

1. Keep the contract tab open.
2. Copy newly written or changed text into a safe temporary document.
3. Note any fields, clauses or formatting you changed.
4. Take note of the visible save status or error message.

Avoid editing the same contract in several tabs at once. Competing versions make it harder to tell which change is current.

## Check the likely cause

Confirm that your internet connection is stable and that you are still signed in. Make sure you have not switched to another organisation and that the contract is still editable. A contract that has moved out of draft or is open in a read-only state will not behave like an editable draft.

Wait briefly for the autosave state to complete. If it succeeds, reopen the contract from **Contracts** and verify the latest content. If the connection failed, restore it before trying a small test change.

Only refresh after your unsaved text is safely copied. Do not repeatedly paste the full document until you know the editor is saving again.

## Contact support

If saving still fails, provide the organisation name, contract title or ID, approximate time, browser, the save state or exact error, and the type of change that failed. Mention whether another tab or user was editing the contract.

Do not send confidential contract text unless support specifically requests an approved example. For normal editor formatting, see [Format contract terms in the editor](/help/templates-and-the-editor/format-contract-terms-in-the-editor).
