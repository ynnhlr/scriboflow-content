# Create a template from an existing contract

When the action is available, **Make template** creates a reusable template from an editor-created contract. Use it to preserve a useful structure without changing the original contract.

## Check that the contract is suitable

The action applies to contracts created in Scriboflow's editor where **Make template** is available. An imported document may not offer the same action because its source content is handled differently.

Before creating the template, review the contract for information that belongs only to the current agreement. Names, prices, dates, party details and negotiation-specific wording should not become reusable by accident.

## Make the template

1. Open the eligible contract.
2. Select the available **Make template** action.
3. Give the new template a clear name.
4. Open the created template in your Library.
5. Remove transaction-specific content and add reusable fields or references.
6. Confirm that the template changes have saved.

The contract and template remain separate. Later template edits do not rewrite the source contract, and later contract edits do not update the template.

## Prepare it for reuse

Replace fixed values with data fields where users must supply a value for each new contract. Use party references and signer fields for participant information, and reusable clauses for wording managed centrally in the Library.

Start a test draft from the template and preview it before colleagues rely on it. Check headings, field placement and any example text. For editing tools, see [Format contract terms in the editor](/help/templates-and-the-editor/format-contract-terms-in-the-editor).
