# Find and filter contracts

Open **Contracts** to search and organize the contracts in your organisation.

## Search the contract list

<!-- help-image:search -->
![Search](../../assets/find-and-filter-contracts/search-v1.webp)

Use the search field to look for a contract by:

- Contract name
- Email address
- Company name

Search works together with the active filters. If a contract is missing from the results, clear the search or filters and try again.

## Apply filters

<!-- help-image:filter -->
![Filter](../../assets/find-and-filter-contracts/filter-v1.webp)

Use the available controls to narrow the list by:

- Status, including **Drafted**, **Pending**, **Changes requested**, **Signed**, **Rejected** and **Expired**
- **Needs attention** for contracts awaiting follow-up
- Created or signed date
- A preset or custom date period
- Tags
- Archived contracts

Select an active filter again or use **Clear filter** to remove it.

## Sort and adjust the table

<!-- help-image:sort -->
![Sort](../../assets/find-and-filter-contracts/sort-v1.webp)

Select a column heading to sort the visible contracts. You can sort by fields such as contract name, status, creation date and latest activity.

Use the column control to show additional information, including the current flow step, signature method, signing deadline, signed date or updated date. Your available columns may depend on the screen width.
