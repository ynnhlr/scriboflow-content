# Set up multi-factor authentication

Multi-factor authentication, or MFA, adds a code from an authenticator app as a second sign-in step.

## Enable MFA

<!-- help-image:image -->
![Security](../../assets/set-up-multi-factor-authentication/image-v1.webp)

1. Open **Settings** and select **Profile**.
2. Find the **Security** section.
3. Select **Enable MFA**.
4. Scan the QR code with an authenticator app. You can also copy the setup key into the app manually.
5. Enter the six-digit code from the authenticator app.
6. Select **Enable**.

After setup, Scriboflow asks for a current six-digit authenticator code when additional verification is required.

## Disable MFA

Open the same **Security** section and select **Disable MFA**. Scriboflow may ask you to verify your current session before completing the change.

Keep access to the authenticator app after enabling MFA. If you lose access and cannot sign in, [contact Scriboflow](/contact) for help. Do not send your authenticator setup key or codes to anyone.
