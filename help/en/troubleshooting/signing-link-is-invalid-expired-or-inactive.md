# A signing link is invalid, expired or inactive

A secure signing link is intended for one recipient and the current contract flow. It may stop working after it expires, is replaced or the contract becomes inactive.

## Check the newest email

Open the most recent Scriboflow email for the contract. If the sender resent the signing link, discard older messages and use the new one. Copying a truncated URL from an email or chat can also make it invalid, so open the email's link directly.

Do not forward the link to another person. If a different recipient should act, the sender must update the contract through the available Scriboflow actions.

## Ask the sender to check the contract

The sender should open the contract and confirm:

- The contract is still active and awaiting this recipient
- The recipient email address is correct
- Signing order has reached this person
- The signing deadline and contract status still allow action

If appropriate, the sender can use the available resend action to issue a fresh email. Resending does not reactivate a contract that has been completed, voided, rejected or otherwise made inactive.

## Contact support safely

If the latest link still fails while the recipient should be active, provide support with the organisation name, contract title or ID, recipient email, current status, approximate resend time, browser and exact error message.

Never send the active signing URL, passwords or verification codes to support. The sender can review [Track signing progress and resend signing links](/help/sending-and-signing/track-signing-progress-and-resend-signing-links), while recipients can simply request a new email from the sender.
