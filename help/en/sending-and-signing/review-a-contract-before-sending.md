# Review a contract before sending

A final review helps you catch missing information before an external recipient receives the contract. Scriboflow also validates required sending details and shows what still needs attention.

## Check the agreement

Open **Preview** and read the complete contract as the recipient will see it. Confirm:

- The title and terms belong to the intended agreement
- Party names and details are correct
- Every required data field has a value
- Smart references display the intended party or signee
- Attachments are present, readable and in the correct order

If the contract was imported, check the document pages carefully. If it was created in the editor, wait for the latest changes to save before previewing.

## Check the signing setup

Review each signee's name and email address. Confirm the selected signature method and whether signing order should apply. A wrong email can send access to the wrong person, so correct it before sending rather than relying on a resend.

Set a future signing deadline and the reminder schedule appropriate for the agreement. See [Manage signing deadlines and reminders](/help/creating-and-managing-contracts/manage-signing-deadlines-and-reminders) for details.

## Check the email and send

Review the subject and message that recipients will receive. Make the requested action and context clear without placing sensitive information in the email unnecessarily.

If Scriboflow reports a missing requirement, return to the named contract step and complete it. Send only when the preview, recipients and delivery details agree. After sending, use the contract status and activity history to confirm that the external send succeeded.
