# An existing document cannot be imported

Import creates a contract from a source document. Start by checking the original file rather than repeatedly uploading renamed copies.

## Check the file

Open the document on your computer and confirm that it is readable, complete and not password-protected or corrupted. Scriboflow currently accepts source documents with these extensions: PDF, DOC, DOCX, HTM, HTML, MD, TEXT and TXT.

The extension must match the real file type. Renaming an unsupported file to `.pdf` or `.docx` does not convert it. Export a clean copy from the application that created the document when needed.

## Understand the result

PDF content remains a fixed document. Word and supported text or HTML content can be converted for editing. Conversion may not reproduce every complex layout exactly, so review the complete imported contract before adding parties or sending.

1. Return to **Import document**.
2. Choose the clean local source file.
3. Keep the page open while upload and processing finish.
4. Open the resulting draft and review all pages or editable terms.

Do not send the contract until headings, tables, page order and text are correct.

## If import still fails

Try a newly exported copy in a supported format. Preserve the original document and any error message.

Contact support with the organisation name, filename and extension, approximate file size, source application, attempt time, browser and exact error. Do not attach a confidential contract unless your organisation approves sharing it through the support channel. For files that should accompany rather than become the contract, see [Add and manage contract attachments](/help/creating-and-managing-contracts/add-and-manage-contract-attachments).
