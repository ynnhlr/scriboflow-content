# Create and manage a saved template

A saved template keeps reusable contract content inside your organisation. Build it around the structure your team needs repeatedly, then create separate contracts from it.

## Create a saved template

1. Open **Library** and go to the templates area.
2. Choose the action to create a template.
3. Give it a specific, recognisable name.
4. Add and format the reusable terms.
5. Insert relevant clauses, data fields, party references or signer fields.
6. Check that your changes have saved before leaving.

Keep transaction-specific names, dates and amounts out of the reusable text. Use data fields or references where the value should be supplied for each contract.

## Manage existing templates

Open a saved template when you need to update the version used for future contracts. Available actions let you edit, rename, duplicate or delete saved templates. Duplicating is useful when two versions share a structure but should develop separately.

Editing a template does not rewrite contracts that were already created from it. Those contracts are independent drafts and retain the content they received at creation.

Before deleting a template, confirm that colleagues no longer need it. Deletion removes that starting point but does not delete existing contracts made from it.

## Keep templates reliable

Use names that identify the agreement and intended audience. Review templates when your organisation changes its standard wording or process, and remove outdated duplicates according to your internal approval practice.

To use the result, see [Start a contract from a template](/help/templates-and-the-editor/start-a-contract-from-a-template). For an existing editor-created contract, see [Create a template from an existing contract](/help/templates-and-the-editor/create-a-template-from-an-existing-contract).
