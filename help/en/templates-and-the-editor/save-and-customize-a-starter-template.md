# Save and customize a starter template

A starter template gives you ready-made content to review. Save an organisation-owned copy before customising it so the original starter remains available and your team can reuse the adapted version.

## Save a copy

1. Open the starter templates in Scriboflow.
2. Select the starter you want to review.
3. Use the available save or customise action.
4. Give the saved copy a name that identifies its intended use.
5. Open the new saved template in the editor.

The saved copy belongs to your organisation. Changes to it do not alter Scriboflow's starter template.

## Adapt the content

Read the complete template before making it available to colleagues. Replace example wording with the terms your organisation intends to use, remove irrelevant sections and format headings or lists consistently.

Use reusable clauses for sections managed in your Library. Add data fields for values that must be completed for each contract, and use party references or signer fields where contract participants should appear automatically. Check that no example names, dates or amounts remain.

## Use and maintain the copy

Starting from the saved template creates an independent contract draft. You can change that draft for the specific agreement without changing the reusable template.

Return to the saved template when future contracts should receive updated wording. Existing contracts are not rewritten by later template changes. Review your saved templates periodically and rename or remove outdated versions so colleagues can select confidently.
