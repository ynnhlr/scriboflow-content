# Respond to requested changes

When a recipient requests changes, Scriboflow pauses the current signing process and changes the contract status to **Changes requested**.

## Review the request

1. Open **Contracts**.
2. Use **Needs attention** or **Changes requested** to find the contract.
3. Open the contract and read the recipient's notes under **Review notes**.
4. Check the timeline to see who submitted the request and when.

If anything is unclear, discuss the requested changes with the recipient outside the signing page before updating the agreement.

## Update the contract

Return to the relevant contract steps and make the agreed changes. Review the parties, terms, attachments and signer setup, especially if the requested change affects names, responsibilities or supporting files.

Use **Preview** to check the revised version. Continue to the final review and send the updated contract when it is ready. Scriboflow records that the previous change request was resolved and starts the revised signing process.

A rejected, expired or fully signed contract cannot be edited through this change-request flow.
