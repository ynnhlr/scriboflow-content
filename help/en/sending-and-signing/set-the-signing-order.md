# Set the signing order

Signing order controls when each signee receives access to act on the contract. Use a sequence when one person's action must come before another's; otherwise let signees act in any order.

## Choose any order or in order

With no required order, Scriboflow can send access to all signees and they can act independently. This is useful when there is no approval sequence between them.

With signing order enabled, the first signee acts before the next person receives access. Scriboflow continues through the ordered list as the required actions are completed.

## Set the sequence

1. Open the contract's signee or signing settings.
2. Add every required signee with the correct name and email address.
3. Enable signing order when a sequence is required.
4. Arrange the signees in the intended order.
5. Review the list in **Preview** before sending.

Check the order carefully. A later signee will wait for earlier recipients, so an unavailable person can delay the whole process. Set an appropriate deadline and reminders using [Manage signing deadlines and reminders](/help/creating-and-managing-contracts/manage-signing-deadlines-and-reminders).

## Follow progress

After sending, open the contract to see which signee is awaiting action. The activity history records the progress through the flow. Resending a signing email gives the relevant recipient access to the current contract; it does not skip a required earlier signee or change the order.

If the participant list itself must change after sending, review the contract's current status and available actions before proceeding. Do not share one recipient's secure link with another person.
