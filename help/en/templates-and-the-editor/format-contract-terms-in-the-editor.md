# Format contract terms in the editor

Use Scriboflow's editor to structure contracts created from scratch, templates or other editable content. Clear formatting makes the document easier to review before it reaches signees.

## Structure the terms

Select text and use the available editor controls to apply headings, paragraphs, bold or italic emphasis, lists, links and other supported formatting. Use headings in a consistent order and keep lists focused on related items.

Avoid using bold for entire paragraphs or relying on formatting alone to explain a legal distinction. The words should remain clear when read in the contract preview and completed PDF.

## Work with autosave

Editor-created contracts save changes as you work. Watch for the current save state and allow the latest update to complete before closing the tab, changing organisations or losing your connection.

If changes appear not to save, keep the page open and copy any newly written text to a safe temporary document before refreshing. Then see [Contract changes are not saving](/help/troubleshooting/contract-changes-are-not-saving).

## Check the complete document

Inserted clauses, data fields and smart references become part of the contract terms. Review their placement and surrounding punctuation after insertion. Complete every required data-field value before sending.

Open **Preview** to check page flow, headings, lists and references in context. The preview is the best place to catch spacing or content issues that are less obvious in the editor. When reusable wording belongs in the Library, continue with [Create and insert reusable clauses](/help/templates-and-the-editor/create-and-insert-reusable-clauses).
