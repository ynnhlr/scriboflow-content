# Create and insert reusable clauses

Reusable clauses help your organisation keep frequently used wording in the Library instead of copying it between contracts. Insert a clause as a starting point, then review it in the context of the agreement.

## Create a clause

1. Open **Library** and go to the clauses area.
2. Choose the action to create a clause.
3. Give it a name that explains its purpose.
4. Add and format the reusable wording.
5. Save the clause and confirm it appears in the Library.

Keep each clause focused enough that colleagues can understand when it applies. Use your organisation's approval process before presenting wording as a standard option.

## Insert a clause

Open an editable contract or saved template and place the cursor where the wording should appear. Use the editor's clause action, select the relevant Library item and insert it.

After insertion, read the surrounding sections. Check numbering, headings, defined terms and references to other clauses. Reusable wording can still require changes for a particular agreement.

## Maintain the Library

Use clear names and avoid indistinguishable duplicates. When standard wording changes, update the Library item for future use and tell relevant colleagues which version is current.

Changing a Library clause does not automatically rewrite wording already inserted into existing contracts. Review active documents separately when a change matters to them.

For values that should vary from contract to contract, use data fields instead of embedding example details in a clause. See [Use data fields, party references and signer fields](/help/templates-and-the-editor/use-data-fields-party-references-and-signer-fields).
