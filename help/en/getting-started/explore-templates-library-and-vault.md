# Explore Templates, Library and Vault

Scriboflow separates reusable contract content from supporting files, making it easier to start consistently and find approved material again.

## Start with Templates

Templates provide a repeatable starting point for new contracts. Starter templates are supplied as ready-made examples, while saved templates belong to your organisation and contain the content your team chooses to reuse.

Starting from a template creates a new contract. Updating that contract does not rewrite the original template. If you need to change future copies, edit the saved template itself. See [Understand starter and saved templates](/help/templates-and-the-editor/understand-starter-and-saved-templates) for the full distinction.

## Reuse content from the Library

The Library gives you access to reusable building blocks such as clauses and data fields. Clauses let you insert approved sections without copying text between documents. Data fields hold values that can be placed into contracts and completed when required.

Review inserted content in the editor before sending. Reusable content gives you a consistent starting point, but each contract should still reflect the agreement you intend to make.

## Store supporting files in Vault

Vault is for documents that you want to keep available for reuse, such as annexes, schedules or frequently used supporting material. A Vault document is not automatically attached to every contract. Select the relevant file when a contract needs it, then confirm it appears in the contract's attachments.

Use clear names for templates, clauses and Vault files so other team members can understand when to use them. Keep outdated items separate or remove them according to your organisation's own content process.
