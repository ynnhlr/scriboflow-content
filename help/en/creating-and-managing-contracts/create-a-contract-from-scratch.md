# Create a contract from scratch

Start with a blank contract when you want to write the agreement directly in Scriboflow.

## Start a new draft

<!-- help-image:start-new -->
![Start new contract](../../assets/create-a-contract-from-scratch/start-new-v1.webp)

1. Open the dashboard or **Contracts**.
2. Select **Create contract**.
3. Choose **Start new**, then select **Start**.

Scriboflow creates an untitled draft and opens the contract flow. You can rename the contract from the heading at the top of the page.

## Complete the contract flow

Work through the steps in order:

1. **Parties:** Add the companies or individuals involved and select their signees.
2. **Terms:** Write and format the agreement. You can also insert saved clauses, data fields and party references.
3. **Attachments:** Add any supporting files that should accompany the contract.
4. **Signature:** Choose the signature method, signing order and reminder frequency.
5. **Review:** Check the contract, recipients and sending details before sending.

Your contract remains a draft until it is sent. Scriboflow saves changes while you work, but check the saved status before leaving the page.
