# Use data fields, party references and signer fields

Fields and smart references let a contract use values from its structured details instead of repeating them manually throughout the terms. They are especially useful in saved templates.

## Choose the right element

Use a data field for a value your organisation wants to reuse or complete for each contract, such as a commercial detail. Use a party reference when the text should show information from a selected contract party. Use a signer field when the content relates to a selected signee.

These elements are placeholders until the relevant value or participant is supplied. Their displayed result depends on the current contract details.

## Insert and complete fields

1. Place the cursor at the relevant point in the editor.
2. Choose the available field or reference action.
3. Select the data field, party information or signer information you need.
4. Add or select the matching contract value or participant.
5. Read the full sentence and adjust surrounding punctuation.

Required data fields must have values before the contract can be sent. If Scriboflow reports a missing value, return to the contract details and complete the named field rather than replacing the reference with unstructured text.

## Review smart content

If you change a party or signee, review every reference that depends on that person. Open **Preview** and check that names and values appear in the intended place and form.

For repeated legal wording rather than changing values, use [Create and insert reusable clauses](/help/templates-and-the-editor/create-and-insert-reusable-clauses). For participant roles, see [Understand parties, signees and team members](/help/getting-started/understand-parties-signees-and-team-members).
